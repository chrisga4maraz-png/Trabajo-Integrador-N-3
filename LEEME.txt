DESCRIPCIÓN
Sitio web estático con contenido sobre League of Legends.
Incluye inicio de sesión, navegación entre páginas, calculadora,
formularios de perfil de jugador y de contacto.

REPOSITORIO
https://github.com/chrisga4maraz-png/Trabajo-Integrador-N-3

TECNOLOGÍAS UTILIZADAS
- HTML5
- CSS3
- JavaScript
- GitHub y GitHub Pages

FUNCIONALIDADES
- Inicio de sesión con validación.
- Protección básica de las páginas internas mediante sessionStorage.
- Navegación por secciones y enlaces entre páginas.
- Calculadora con suma, resta, multiplicación y división.
- Validación de datos en los formularios.
- Formulario de perfil gamer.
- Formulario de contacto con ventana de confirmación.
- Diseño adaptable a distintos tamaños de pantalla.

INSTRUCCIONES DE EJECUCIÓN
1. Descargar o clonar el repositorio.
2. Abrir index.html en un navegador.
3. Utilizar los datos de acceso de prueba.
4. Al ingresar, se abre la calculadora.
5. Desde el menú se puede navegar por las demás secciones.
